# Sentiment Classification on Product Reviews

## 1. Problem Statement

Build an end-to-end machine learning system that classifies product reviews as positive or negative using natural language processing and classical machine learning techniques.

## 2. Dataset

Amazon Fine Food Reviews dataset.

The project will use a manageable stratified sample of the dataset. Reviews with 3-star ratings will be excluded because they represent ambiguous sentiment.
